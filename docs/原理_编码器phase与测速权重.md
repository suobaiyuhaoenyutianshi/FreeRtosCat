# 原理：编码器 phase、边沿识别与测速权重

- 记录时间：2026-11-17
- 对应代码：`Core/Src/app_encoder.c`
- 相关变更：[变更记录_上电自动标定.md](变更记录_上电自动标定.md)

## 一、phase 是什么

`phase_l` / `phase_r` 不是电机相位角，也不是转向，它只保存**A 相边沿发生后的电平（0/1）**。

HAL 的 EXTI 回调只告诉软件“这个引脚出现了边沿”，**不告诉是上升沿还是下降沿**：

```c
void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
```

所以中断里重新读一次 A 脚，把结果存进 phase：

- 读到 A = 1 → 刚才一定是**上升沿**；
- 读到 A = 0 → 刚才一定是**下降沿**。

这一个 0/1 状态同时记录了“当前电平”和“刚才是什么边沿”，后面标定和测速都要用它。

## 二、波形与映射

![A 相边沿与 phase 的对应关系](encoder_phase_edge_mapping.svg)

*图注：上升沿后 phase=1，刚结束的是低电平段；下降沿后 phase=0，刚结束的是高电平段。*

| 边沿 | 边沿后 A | phase | 刚结束的那一段 | 标定累加 | 测速权重 |
| --- | --- | --- | --- | --- | --- |
| 上升沿 | 1 | 1 | 低电平 | `cal_low_ticks += dt` | `m[1] = 2(1-D)` |
| 下降沿 | 0 | 0 | 高电平 | `cal_high_ticks += dt` | `m[0] = 2D` |

其中 `D` 是该轮编码器 A 相的高电平占比，左右轮各自测量，所以 `D` 和 `m` 都分左右两套。

## 三、标定中的用途

A 相一个完整周期 = 高电平段 + 低电平段。每个边沿发生时，中断里已经算出刚结束那一段的时长：

```c
uint32_t dt = t0 - t1;      /* 相邻两个边沿之间的时长 */
```

用 phase 判断它属于高还是低：

```c
if (phase_l == 0U) { cal_high_ticks += dt; }   /* 下降沿：刚结束的是高 */
else               { cal_low_ticks  += dt; }   /* 上升沿：刚结束的是低 */
```

300ms 统计窗口结束后：

```
DUTY = 高电平总时长 / (高电平总时长 + 低电平总时长)
```

这里不是逐周期求占空比再平均，而是把所有高电平时长、低电平时长分别累加，最后只做一次除法。这样得到的是按时间加权的占空比，更符合“整段时间里高电平占了多少”的物理定义。

## 四、测速中的用途

测速 M/T 算法需要知道当前用的是高电平段还是低电平段，因为两段时长不相等。

权重定义：

```c
m[0] = 2D;        /* 高电平段的权重 */
m[1] = 2(1-D);    /* 低电平段的权重 */
```

测速函数中：

```c
uint8_t next_ph = phase ^ 1;
float mo   = dir * m_l[phase];     /* 刚结束那一段的权重 */
float mNow = dir * m_l[next_ph];   /* 当前正在进行那一段的权重 */
```

- `m_l[phase]` 对应刚结束的段，时长是 `t0 - t1`；
- `m_l[phase ^ 1]` 对应当前段，时长是 `now - t0`；
- 两者比较后，选择其中一个区间做 `M / T` 测速。

### 数值例子

设 `D = 0.49`，则：

```
m[0] = 0.98    （高电平段）
m[1] = 1.02    （低电平段）
```

假设实测低电平段持续 `1.02ms`：

- 真实完整周期：`T = 1.02 / (1 - 0.49) = 2.0ms`
- 用权重：`M / T = 1.02 / 1.02ms = 1.0/ms`，正好等于 `2 / 2ms`
- 不用权重：`1 / 1.02ms = 0.98/ms`，速度偏低约 2%

所以 `m` 权重就是用来抵消“高、低电平时间不等”带来的测速偏差。`m` 本身无量纲，`M/T` 的量纲是 `1/ms`，后续再乘每计数对应的弧度常数。

## 五、左右轮为什么各有一套

- `phase_l` 只由左轮 A 相边沿更新，`phase_r` 只由右轮更新；
- `g_duty_l` / `g_duty_r` 分别测量、分别保存；
- `m_l` / `m_r` 分别由各自的 DUTY 计算。

因此左轮的占空比或权重不会影响右轮。

## 六、常见误区

1. **phase 不是电机电角度**，只是一个 A 相电平标记；
2. **phase 不负责判方向**，方向由 A 边沿时刻的 B 相电平决定（`A == B` 为正，`A != B` 为负）；
3. **DUTY 不是电机 PWM 占空比**，而是编码器 A 相高电平占比，只用于测速权重；
4. **不能靠数边沿个数测占空比**：一个完整周期里高、低电平各有一个边沿，个数永远是 1:1，必须累加持续时间。

## 七、标定失败时的行为

以下任一条件成立时，该轮测量作废，保留原来的 `g_duty_l/g_duty_r`：

- 有效边沿数 `< CAL_MIN_EDGES`（20）；
- 高电平或低电平总时长为 0；
- 算出的占空比不在 `[0.30, 0.70]`。

串口会打印：

```
CAL L: FAIL, keep 500/1000
```
