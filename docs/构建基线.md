## 2. 复现命令

```powershell
$tmp = Join-Path $env:TEMP "t1_baseline"
if (Test-Path $tmp) { Remove-Item -Recurse -Force $tmp }
New-Item -ItemType Directory -Path $tmp | Out-Null
$zip = Join-Path $env:TEMP "t1_base.zip"
git archive --format=zip -o $zip HEAD
Expand-Archive -Path $zip -DestinationPath $tmp -Force
Set-Location $tmp

cmake --preset Debug;      cmake --build --preset Debug
cmake --preset MinSizeRel; cmake --build --preset MinSizeRel
cmake --preset Release;    cmake --build --preset Release
```

## 3. 结果

| 构型 | 优化参数 | FLASH（`size`：text+data） | RAM（`size`：data+bss） | 结果 |
|---|---|---|---|---|
| Debug | `-Og -g3` | 49,712 B（75.85%） | 14,512 B（70.86%） | PASS，0 warning |
| MinSizeRel | `-Os -g0 -DNDEBUG` | **44,840 B（68.42%）** | 14,512 B（70.86%） | PASS，0 warning |
| Release | `-Os -g0` 后又追加 `-O3 -DNDEBUG` | 52,956 B（80.82%） | 14,512 B（70.86%） | PASS，0 warning |

- `size` 明细（Debug）：`text 49,608 + data 104 + bss 14,408`；`ld --print-memory-usage` 报 FLASH 49,716 B / RAM 14,512 B，二者 4 B 差来自输出段对齐，本文以 `size` 口径为准。
- RAM 未分配（主栈 MSP 可用）：20,480 − 14,512 = **5,968 B**（`_estack = 0x2000_5000`，已分配区顶到 `0x2000_38B0`）。
- 与 2026-11-16 基线（48,184 B / 14,480 B）相比：FLASH +1,528 B（上电自动标定 + 启动版本行 + 警告修复），RAM +32 B，均仍在预算内。

## 4. 结论与规则

1. **发布统一用 MinSizeRel**：44,840 B，相比 Debug 省 4.9 KB。
2. **Release 预设不可用于发布**：`CMAKE_C_FLAGS_RELEASE` 的 `-O3` 追加在工具链 `-Os` 之后，实际生效 `-O3`，体积比 Debug 还大 3.2 KB。
3. **Flash 预算**（T1 分区方案 A：Boot 8 KB + App 54 KB + 参数 2×1 KB）：
   - App 区域 55,296 B；
   - 按 MinSizeRel 计算余量 **10,456 B（18.9%）**；
   - 按 Debug 计算余量 **5,584 B（10.1%）**。
4. 任何批次合入前记录本表；App 余量低于 4 KB 时暂停新增功能并上报。
5. **版本号**：配置阶段由 `git describe --tags --always --dirty` 注入 `FW_VERSION`，随首行串口打印；无 `.git` 的源码导出回退为 `dev`。
