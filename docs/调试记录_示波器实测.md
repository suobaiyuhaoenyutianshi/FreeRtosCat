## 2. 测量前准备

- [ ] 车轮架空（`App_Encoder_AutoCalibrate()` 上电会直接驱动电机）。
- [ ] 共地：探头地夹接板子 GND，尽量短。
- [ ] 记录探头衰减（1× / 10×）与量程，截图里要能读到时间轴与幅值。
- [ ] PWM 测点优先选 PA8/PB6；若被电机驱动干扰，改测对应定时器引脚的空载焊盘或排针。
- [ ] 触发方式：PWM 用边沿触发；UART 用下降沿单次触发；I2C 用 SCL 下降沿。

## 4. 推荐的第一条闭环（从易到难）

1. **PWM 占空比**：让固件输出固定占空比（如 `App_PWM_Set_L(0.25f)`），示波器量 PA8：
   频率应为 10 kHz（周期 100 µs），高电平约 25 µs。若频率不对，查 TIM1 PSC/ARR；若占空比不对，查 `App_PWM_Set_L` 的标度。
2. **UART 位宽**：抓 PA2 一帧数据，量起始位到停止位；921600 下 1 位 ≈ 1.085 µs，10 位 ≈ 10.85 µs。
3. **I2C 帧**：抓 PB8/PB9 读 MPU6050 的 14 字节；确认 SCL 频率 ≈ 400 kHz、每字节后 ACK 拉低。

## 5. 没有仪器时的替代验证（不计入本记录验收）

- 用 DWT 周期计数在关键路径打点，把耗时通过 USART2 打印；
- 翻转一个空闲 GPIO（如 PA4），用另一块板/逻辑分析仪抓；
- 用定时器输入捕获测 PWM 频率/占空比，把结果打印出来。

> 替代验证能证明“代码路径”，但不能替代“真实波形”这一条 P1 验收；有仪器后仍需补测。
