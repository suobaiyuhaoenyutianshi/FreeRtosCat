## 2. 逐项改动

### 2.1 启动首行：fw ver / build date / reset cause

- 文件：`Core/Src/main.c`、`CMakeLists.txt`
- 改前：上电只打印 `B1`，没有固件版本与复位原因；版本只能靠 `git log` 猜。
- 改后：
  - CMake 配置阶段执行 `git describe --tags --always --dirty`，以 `FW_VERSION` 编译宏注入；无 `.git` 时回退 `dev`。
  - `main.c` 新增 `prvPrintBootInfo()`，在 USART2 初始化后、调度器启动前阻塞打印：
    `fw <版本> | build <__DATE__> <__TIME__> | reset <IWDG|WWDG|LOWPOWER|SOFTWARE|POWER-ON|PIN|UNKNOWN>`
  - 打印后调用 `__HAL_RCC_CLEAR_RESET_FLAGS()`，保证下一次上电能区分新的复位原因。
- 原因：P1 验收要求“上电到第一行 < 3 s，复位原因能区分上电/看门狗/软复位”。

### 2.2 warning 清零

| 文件 | 改动 | 原因 |
|---|---|---|
| `Core/Src/app_motor.c` | `App_Motor_Proc` 增加 `(void)argument;` | `-Wunused-parameter` |
| `Core/Src/main.c` | 删除调度器后包含嵌套 `/*` 的注释块 | `-Wcomment` |
| `Core/Src/qmath.c` | `binary_search` 增加空表保护并初始化 `mid = 0` | `-Wmaybe-uninitialized`；同时避免 `array_length=0` 时无符号回绕越界 |
| `stm32f103c8tx_flash.ld` | `.ARM.extab/.ARM/.preinit_array/.init_array/.fini_array` 加 `(READONLY)` | 消除链接器 `LOAD segment with RWX permissions` 警告 |

- 改后结果：Debug / MinSizeRel / Release 三构型全部 **0 error 0 warning**。

### 2.3 死代码与链接脚本歧义

- 删除 `Core/Src/app_sys.c`（`App_NvicPriority_Init` 无调用者；优先级编排已在 `main.c` 内联并加注释）。
- `STM32F103xx_FLASH.ld` 顶部加说明：默认 GCC/CMake 构建使用 `stm32f103c8tx_flash.ld`，该文件只用于 `cmake/starm-clang.cmake`，避免读者改错链接脚本。
- `app_motor.c` 末尾注释改为与实现一致：TIM2 中断只 `vTaskNotifyGiveFromISR`，PID 在任务里跑。

## 3. 验证方式与结果

```powershell
# 1) 工作区三构型
cmake --preset Debug;       cmake --build --preset Debug
cmake --preset MinSizeRel;  cmake --build --preset MinSizeRel
cmake --preset Release;     cmake --build --preset Release

# 2) 空目录（排除 .git、build/）
#    复制工作区到 %TEMP%\cartest_delivery_clean 后执行
cmake --preset Debug; cmake --build --preset Debug
```

| 项 | 结果 |
|---|---|
| error / warning | 0 / 0（三构型 + 干净 clone） |
| Debug FLASH / RAM | 49,704 B（75.84%）/ 14,512 B（70.86%） |
| MinSizeRel FLASH / RAM | 44,832 B（68.41%）/ 14,512 B（70.86%） |
| Release FLASH / RAM | 52,948 B（80.79%）/ 14,512 B（70.86%） |
| 干净 clone 版本号 | `baseline-2026-11-16-3-gff07ede` |
| 无 `.git` 目录版本回退 | `Firmware version: dev` |
| 链接段权限 | 第一个 LOAD 段 `R E`（RWX 警告消失） |
| `app_sys.c` | 已删除，干净 clone 构建不再包含该源文件 |
